Tag sets

A tag set is a named selection of labels — the palette you tag with. Switch between sets as the task changes, edit any of them, or build your own. Sets and label definitions are remembered in this browser and export together as one file you can share with other annotators.

Tag sets and the one-class rule

The number keys follow whichever tag set is active, so switching sets switches your palette. Spans may not overlap — a word carries at most one class — so if a new span would cover an existing one, you are asked whether to replace it.
